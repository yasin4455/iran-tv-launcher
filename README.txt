روش نصب روی گوشی بدون ساخت APK:
۱) فایل‌های index.html و manifest.webmanifest و sw.js را در ریشه مخزن GitHub بارگذاری کنید.
۲) Settings > Pages را باز کنید.
۳) در Build and deployment گزینه Deploy from a branch را انتخاب کنید.
۴) Branch را main و Folder را /(root) انتخاب و Save کنید.
۵) پس از انتشار، آدرس GitHub Pages را با Chrome گوشی باز کنید.
۶) منوی سه‌نقطه Chrome > Install app یا Add to Home screen را بزنید.

این روش APK نمی‌سازد؛ وب‌اپ را روی صفحه اصلی گوشی نصب می‌کند.
لینک‌های شبکه‌های ۱ تا ۲۱ نمونه‌اند و ممکن است شناسه‌های پخش زنده نیاز به اصلاح داشته باشند.
